## 🧠 Padrões

### Tamanho de arquivo

- **200–250 linhas**: sinal de que o arquivo pode estar fazendo coisas de mais contextos.
- **300 linhas**: quebrar por responsabilidade (uma regra, um tipo, um conversor, um handler), não por tamanho arbitrário.
- **Arquivos gerados** (`spec/opcodes.yaml`): não cobertos pelo limite manual; deixar o gerador explicar a origem.

### Organização de pastas

| Categoria | Padrão | Exemplo |
|---|---|---|
| Especificação | `docs/` = narrativa; `spec/` = contrato máquina | `docs/02-PROTOCOLO.md`, `spec/opcodes.yaml` |
| Dados | `data/` versiona o que veio da fonte ou foi extraído por script | `data/xp_mortal_arch.csv` |
| Schema | `schema/` guarda DDL versionado; nunca monta DDL no código do app e sim em versão | `schema/001_init.sql` |
| Conversores/ETL | pacote coeso com decoder → modelo → reconciliação → emissão, tudo coberto por teste | `importer/` |
| Serviço | diretório por serventia: protocolo, diretório, server, hashing — cada um com responsabilidade | `gateway/src/{protocol,server,directory,hashing}.rs` |
| Testes | co-localizados com o código ou em `tests/`/`*_test`, com fixtures co-localizados quando específicos | `gateway/tests/`, `tests/fixtures.py` |
| Roadmap | `roadmap/` aloja visão geral + issues detalhadas + agentes | este README + `roadmap/issues/` |

### Ferramentas de qualidade

| Gate | Comando | Estado |
|---|---|---|
| Formatação Rust | `cargo fmt --check` | gate, limpo |
| Lint Rust | `cargo clippy -- -D warnings` | gate, limpo |
| Lint Python | `ruff check .` (regras fixadas em `ruff.toml`) | gate, limpo |
| Testes Python | `python -m pytest tests -q` | gate, 82 testes |
| Links da documentação | `python scripts/verify_spec.py` | gate, cobre `README.md`, `docs/`, `roadmap/`, `skills/`, `.agents/skills/` |
| Formatação Python | `ruff format --check` | **não é gate** — 14 arquivos seriam reformatados; decisão pendente |

> O `ruff` sem configuração de projeto herda regras do ambiente de quem roda. `ruff.toml` existe para o gate não depender da máquina.

### Testes

| Tipo | Responsabilidade | Exemplo |
|---|---|---|
| Unitário | Regras puras: decode, hash, refino, XP, dano. Sem banco, sem rede. | `tests/test_decode.py`, `gateway/src/hashing.rs` em teste |
| Integração | Codificador + decode, round-trip, banco com fixture, credenciais. | `gateway/tests/postgres.rs`, carga em PGlite/PostgreSQL 16 |
| E2E | Do cliente ao servidor e volta, com framing real. | `gateway/tests/e2e.rs` |
| Golden/vetor | Compara bytes gerados com vetor conhecido (captura ou especificação). | Pendente — gate para Fase 3 |
| Fixtures | Entidades sintéticas documentadas, nunca secretas. | `tests/fixtures.py`, `gateway/tests/fixtures/` |
