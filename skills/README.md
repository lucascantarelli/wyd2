# Skills do projeto

As skills canônicas ficam em `.agents/skills/<nome>/SKILL.md`, no formato que o
Freebuff/Codebuff descobre automaticamente (`.agents/skills/<nome>/SKILL.md`, com
frontmatter: `name`, `description`, `metadata.category`).

Elas aparecem como `/skill:<nome>` e são carregadas pelo agente sob demanda. Este
diretório é mantido apenas como ponto de entrada humano, com uma lista curada de cada
habilidade do projeto.
